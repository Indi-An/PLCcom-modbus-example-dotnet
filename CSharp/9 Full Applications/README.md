# 9 Full Applications - C#

The full applications are the hands-on tools for the moments when a small console sample is no longer enough. They are useful for manual validation, customer reproduction cases, certificate checks, byte order experiments, register mode checks, and log inspection.

## Applications

| # | Project | Use it when |
|---|---------|-------------|
| 91 | `91_Full_Master_Sample` | You want to connect as a master, try requests interactively, inspect logs, and manage certificates. |
| 92 | `92_Full_Slave_Sample` | You need a configurable slave with TCP and SecureTCP listeners for master-side tests. |

These applications are intentionally more complete than the console workshops. Treat them as validation tools, not as the first place to learn the API.
