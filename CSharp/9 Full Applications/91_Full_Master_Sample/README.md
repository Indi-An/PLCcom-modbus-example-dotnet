# 91 Full Master Sample

A complete Windows Forms master application for manual PLCcom Modbus validation.

## Before You Run

Open the project in Visual Studio and configure license data, target endpoint, protocol, and request settings in the UI.

Replace the license placeholders before connecting to a PLCcom Modbus endpoint.

## Run

~~~powershell
dotnet run
~~~

## What To Look At

Use it for interactive checks: TCP, SecureTCP, certificate management, logging, byte order, register modes, and device-specific timing.
