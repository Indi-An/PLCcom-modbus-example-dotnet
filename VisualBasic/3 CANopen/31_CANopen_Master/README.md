# 31 CANopen Master

Demonstrates CANopen-style object dictionary access through Modbus from VB.NET.

## Before You Run

Review serial settings, slave id, and object dictionary entries before running against hardware.

Enter your license user name and serial before connecting to a PLCcom Modbus endpoint, or leave both fields blank to run for 15 minutes during a debug session.

## Run

~~~powershell
dotnet run
~~~

## What To Look At

Watch the quality checks and value handling for read and write operations.
