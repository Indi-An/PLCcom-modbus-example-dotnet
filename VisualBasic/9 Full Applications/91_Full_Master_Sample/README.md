# 91 Full Master Sample

A full VB.NET Windows Forms master application for manual validation.

## Before You Run

Open the project in Visual Studio and configure license data, endpoint, protocol, and request settings in the UI.

Enter your license user name and serial before connecting to a PLCcom Modbus endpoint, or leave both fields blank to run for 15 minutes during a debug session.

## Run

~~~powershell
dotnet run
~~~

## What To Look At

Use it to test TCP, SecureTCP, certificate handling, logging, byte order, register modes, and target-specific timing.
