# 9 Full Applications - Visual Basic

The full VB.NET applications mirror the C# validation tools. They are meant for manual checks: start listeners, connect a master, inspect logs, test SecureTCP, review certificates, and reproduce customer scenarios with a visible UI.

## Applications

| # | Project | Use it when |
|---|---------|-------------|
| 91 | `91_Full_Master_Sample` | You want to connect as a master, try requests interactively, inspect logs, and manage certificates. |
| 92 | `92_Full_Slave_Sample` | You need a configurable slave with TCP and SecureTCP listeners for master-side tests. |

Use the small workshops first. Use these applications when you need breadth, UI control, and manual diagnostics.
