# 22 SecureTCP Slave

Hosts a SecureTCP slave listener from VB.NET.

## Before You Run

Run this workshop before `21_SecureTCP_Master` for a local pair.

Enter your license user name and serial before connecting to a PLCcom Modbus endpoint, or leave both fields blank to run for 15 minutes during a debug session.

## Run

~~~powershell
dotnet run
~~~

## What To Look At

Watch the endpoint certificate setup and the rejected/trusted certificate workflow.
