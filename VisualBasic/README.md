# Visual Basic Workshops

This folder mirrors the C# workshop path for VB.NET teams. The numbering, topics, and project names stay aligned with the C# side so that both languages can be compared without mental translation work.

Use these workshops when your application is written in Visual Basic, when you maintain older VB.NET integration tooling, or when you want a direct VB equivalent of a C# sample.

## Chapters

| Chapter | What you learn |
|---------|----------------|
| `1 First Steps` | Plain Modbus TCP with a local slave and a master that reads and writes registers. |
| `2 Secure Modbus TCP` | TLS, PKI store handling, certificate trust, mutual TLS, and role authorization callbacks. |
| `3 CANopen` | CANopen-style object dictionary access through Modbus. |
| `9 Full Applications` | Full Windows Forms master and slave applications for manual validation. |

## Recommended Start

Start the slave workshop first, then the matching master. The master examples are easier to understand when the slave output is visible beside them.
